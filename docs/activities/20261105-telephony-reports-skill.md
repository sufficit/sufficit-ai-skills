# Skill de relatórios de telefonia

Criada sufficit-telephony-reports 1.0.0 (MIT-0), específica para relatórios por
cliente via API e entrega de JSON/XLSX. Inclui catálogo de nove modelos,
autorização PhoneCalls por contexto, datas/fuso, limites, validação de linhas e
totais, cuidados com snapshot, anexos e diagnóstico da incompatibilidade EPPlus.
Não inclui dados reais, credenciais, autorização implícita para mensagens externas
ou procedimentos de deploy na geração ordinária. Referência técnica separada do
fluxo principal; contrato em produção e documentação do Endpoints prevalecem.

Pacote registrado em upstream-v2 e import-manifest com digest SHA-256; índice e
contagem README atualizados para 185 skills. Validadores de pacote e índice
passaram. Cobertura de Markdown e 38 testes do repositório passaram, verificados na árvore
preparada para commit, excluindo plano não versionado de outra tarefa.

Publicação na main não comprova sincronização/instalação do pacote no Genius.
