# Diagnóstico por MAC na skill de telefonia

A versão 0.9.1 de sufficit-telephony-extensions documenta a coluna Diagnóstico no Blazor, a leitura da API e as diferenças entre configuração entregue, resposta HTTP de firmware e versão observada. A referência registra o início da coleta para GXP16xx e a consulta aos logs para eventos anteriores.

O diagnóstico está disponível no Blazor publicado pela execução 45222761969, revisão 77492e42. A API de provisionamento foi publicada na revisão d7ae0d7.
