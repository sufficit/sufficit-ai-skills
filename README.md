# Sufficit AI Genius Skills

Pacotes públicos e versionados de skills mantidas pela Sufficit para o Genius.
Cada pasta em `skills/` contém instruções, recursos sob demanda, metadados de
apresentação, licença e manifesto de versão.

## Skills

| Skill | Uso |
| --- | --- |
| [`github-cli`](skills/github-cli/SKILL.md) | Operações GitHub, anexos e diagnóstico do CI Sufficit com autenticação efêmera do Identity. |

O catálogo do Genius fixa cada pacote em um commit completo. Alterações em
`main` não substituem silenciosamente uma versão já revisada ou instalada.
