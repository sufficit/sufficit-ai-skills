# sufficit-hermes-agents

Administer helpdesk agents in Hermes (Chatwoot) through the live corporate API: create an agent user in an account (conta) with name, e-mail and role, manage availability, issue and rotate agent API tokens, link an agent to a telephony extension (ramal) and offboard agents. Use when a request mentions criar usuario/agente no Chatwoot ou Hermes, conta/instance, token de API do agente, vincular ramal ao agente or desativar agente. Not for self-service agent reads (hermes-api) and not for the ramal itself (sufficit-telephony-extensions).
