# sufficit-api

Query and manage Sufficit corporate API resources as the authenticated user: telephony low-balance alerts, wallets, credits, vouchers and contacts. Resolve alert amount and primary channel from customer evidence before asking optional questions. Do not use to change source code, access the database directly or invent routes outside the deployed OpenAPI.
