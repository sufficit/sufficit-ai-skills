# metatrader5-orders

Set up MetaTrader 5 with the Python MetaTrader5 library (natively on Windows or under Wine on Linux), connect it to the user's own brokerage account with the password kept in the Sufficit Identity Vault, read quotes, and send orders only on the user's explicit, per-order confirmation behind a two-layer lock (terminal AutoTrading off plus value and symbol limits). Use when a user wants to operate their own account (for example XP Investimentos on B3) through Genius. Living guide, updated as lessons are learned.
