# ixc-api

Call the IXC Provedor (IXCSoft ISP management ERP) REST webservice correctly for every module — customers, contracts and plans, receivables (boleto, PIX, renegotiation), payables, tickets and service orders, Radius logins, connection status, trust unblock, fiber ONU/OLT, inventory, purchasing, sales, CRM, VoIP and administration — with Basic auth (user id + token), the ixcsoft: listar search header, grid_param filters and safe write rules. Also ships a tested-pattern tool pack for Sufficit Fleet voice and chat agents.
