# Prompts for each part of the profile

Fill the `<...>` slots with facts from the user. Do not run a prompt with empty
slots; ask for the missing facts instead.

## Name field

> Write 5 options for the Instagram name field of `<brand>`, which `<what it does>`
> for `<audience>`. Format: brand + short description. Each option must start with
> the brand, contain the search term `<keyword customers type>`, and fit in 30
> characters. Show the character count of each.

## Bio

> Write 3 Instagram bios (max 150 characters each, count them) for `<brand>`.
> Line 1: the result it delivers for `<audience>`. Line 2: proof — `<real number,
> client or result>`. Line 3: a call to action to `<next step>` via the link. No
> hashtags, at most two emojis, plain language.

## Link and WhatsApp message

> Write the prefilled WhatsApp message a visitor from Instagram sends to
> `<brand>` when tapping the bio link. Under 80 characters, friendly, and it must
> let the team know the lead came from Instagram.

## Highlights

> Propose 5 Instagram highlights for `<brand>` that answer the questions a buyer
> of `<product>` has before buying. For each: a one-word title, the cover icon
> idea, and 3 story ideas using this material: `<results, testimonials, offer,
> FAQ>`.

## Pinned posts

> Write briefs for 3 pinned Instagram posts for `<brand>`:
> 1) how it works — show `<product/service>` solving `<problem>`;
> 2) client case — `<client, problem, solution, measurable result>`;
> 3) who we are — `<founder/team story and why we do this>`.
> For each: format (Reel or carousel), hook for the first 2 seconds, outline and
> a single call to action.

## Profile audit

> Audit this Instagram profile: photo `<description>`, name field `<text>`, bio
> `<text>`, link `<url>`, highlights `<titles>`, pinned posts `<topics>`. Rate each
> element against: searchable keyword, clear outcome, proof, next step, trust
> material. Say which step of the ladder it reaches (photo → name → bio → link →
> highlights → pinned → content) and list the 3 highest-impact fixes.
