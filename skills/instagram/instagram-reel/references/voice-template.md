# Brand voice template

Copy to `instagram/<handle>/voice.md` in the brand's own project and fill it in the
brand's language. Prefer inferring it from three real Reels or captions, then ask the
user to correct the draft. Leave unknown fields blank; never guess them.

Keep this file private when it holds unpublished figures or client names. Do not
commit those to a public repository, and never store credentials here.
