# hermes-api

Connect your own Hermes (Chatwoot) account with a personal token and Identity Vault, guide beginners to their token page, and complete authorized helpdesk requests: locate contacts or groups, open an attendance, send text/PDF and verify delivery. Discover the live API when a tool is missing. Also manage your profile/avatar and private notes. Missing tools or environment variables do not prove missing access.
