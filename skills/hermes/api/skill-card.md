# hermes-api

Complete authorized Hermes helpdesk requests from ordinary language: locate the customer or WhatsApp group, open an attendance, send text and PDF attachments, and verify the result. Discover the live API and use the connected user's Identity Vault token when a ready-made tool is missing. Also manage your own profile/avatar and private notes. Do not infer lack of access from missing tools or environment variables.
