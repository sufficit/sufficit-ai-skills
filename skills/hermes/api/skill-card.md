# hermes-api

Use the Hermes HTTP API (Sufficit's Chatwoot-based helpdesk) as your own user: discover the live API from the server's OpenAPI document instead of memorizing routes, authenticate with your personal token (Authorization Bearer), confirm who and which account you are, update your own profile and avatar, read conversations and post private notes.

In Genius, use Vault-backed tools to find contact conversations, open an attendance in a chosen inbox and assign an agent with explicit authorization.
