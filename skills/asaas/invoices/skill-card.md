# asaas-invoices

Query and schedule production ASAAS NFS-e invoices with asaas_invoices_list, asaas_services_list, and asaas_invoices_create; cancel with asaas_invoices_cancel when available. Omit municipal service fields by default so account configuration supplies them. Never ask the user for a municipal code or invent one. Invoice descriptions come from the user. Municipal fields can create service entries or change existing invoice associations. Consult official documentation before assuming requirements, report discrepancies, query before writing, and obtain approval.
